# Salty Dog — как пользоваться

## Быстрый старт

```bash
# 1. Установить зависимости (один раз)
python -m venv .venv && source .venv/bin/activate && pip install -e .

# 2. Указать путь к Obsidian-хранилищу в .env
VAULT_PATH=/путь/к/папке/Charter 2026 Croatia

# 3. Собрать контент из заметок
make build

# 4. Запустить сервер
make dev
# Открыть http://localhost:8000
```

## Обновил заметку в Obsidian

Контент не подтягивается автоматически. После правок в Obsidian:

```bash
make build   # пересобрать content.json
```

Если dev-сервер запущен — просто обнови страницу в браузере (Cmd+Shift+R).

## Добавить новую заметку

1. Создай `.md` файл в папке vault
2. Открой `_app.yaml` в той же папке
3. Добавь файл в нужную секцию:

```yaml
# Без шаблона — покажется как аккордеон с HTML
files:
  - "Название файла"

# С шаблоном — покажется как дизайнерская карточка
files:
  - file: "Название файла"
    template: "имя_шаблона"
```

4. `make build`

### Доступные шаблоны

| Шаблон | Что рендерит |
|--------|-------------|
| `route_plan` | Таймлайн маршрута по дням |
| `travel_logistics` | Обратный отсчёт + карточки перелётов и трансферов |
| `safety_briefing` | Протоколы безопасности с чекбоксами |
| `emergency_contacts` | Карточки контактов и VHF-каналов |
| `kids_on_board` | Правила, снаряжение, активности для детей |
| `crew_list` | Карточки экипажа + вахтенное расписание |
| `equipment_checklist` | Чеклист снаряжения по категориям |
| `provisions` | Списки закупок + план питания |

Если шаблон не указан или structured data пустая — страница покажется в обычном аккордеоне (fallback).

## Удалить контент

**Убрать страницу:** удали строку из `files:` в `_app.yaml`, затем `make build`.

**Убрать целую секцию:** удали блок секции из `_app.yaml`, затем `make build`.

**Сам `.md` файл** удалять не обязательно — если его нет в `_app.yaml`, он просто игнорируется.

## Структура `_app.yaml`

```yaml
trip:
  name: "Croatia 2026"
  boat: "Bavaria 46"          # показывается в шапке
  dates: "28 июня — 5 июля"   # показывается в шапке
  departure_date: "2026-07-01" # ISO-дата для обратного отсчёта

sections:
  - id: route          # уникальный ID
    title: "Маршрут"   # название в интерфейсе
    icon: "🗺️"         # эмоджи-иконка
    tab: map           # вкладка: map | plan | tips | crew
    files:
      - file: "Route plan"
        template: "route_plan"
      - "Ports & anchorages"
```

## Вкладки

| tab | Название | Что туда класть |
|-----|----------|----------------|
| `map` | Карта | Маршрут, порты, якорные стоянки |
| `plan` | План | Логистика перелётов, расписание |
| `tips` | Советы | Безопасность, дети, экстренные контакты |
| `crew` | Экипаж | Список экипажа, снаряжение, провизия |

## Офлайн

Приложение — PWA. После первого открытия работает без интернета. Данные кешируются service worker'ом. При обновлении контента — нужен один раз онлайн для обновления кеша.
